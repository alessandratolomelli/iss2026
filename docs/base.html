Firefly

Introduction

Goal: definere un modello qak di un sistema firefly che simula il comportamento di una lucciola..

Requirements

R1  Simulare il comportamento di una lucciola attraverso la definizione di un modello qak.

R2  Estendere il modello per:
    -3 lucciole
    -100 lucciole

Requirement analysis

In questo Sprint viene preso in considerazione principalmente il requisito R1. Il secondo requisito verrà analizzato in un secondo momento, concentrandosi sulla sincronizzazione del lampeggiamento tra più lucciole.

Il modello qak del sistema deve avere nome firefly e le lucciole devono essere rappresentate da attori indipendenti che lampeggiano con una frequenza variabile nel tempo.

Un esempio di attore che rappresenta una lucciola è il seguente:


QActor firefly1 context ctxfirefly  {     

    [#   
       var  X          = 1
       var  Y          = 1
       var Timer       = 500L 
    #] 

    State s0 initial{
        [# Timer = java.util.Random().nextLong(800L,1500L )  #]  
        println("$name | X=$X Y=$Y  Timer=$Timer") color magenta    
    }
    Goto flash
    
    State flash{
        [# Timer = java.util.Random().nextLong(500L,1000L )  #] 
        delayVar Timer

        println("$name | turnOn $Timer") color cyan
        forward griddisplay -m cellstate : cellstate($X,$Y,1)             

        delayVar Timer    

        forward griddisplay -m cellstate : cellstate($X,$Y,0)     
    }

    Transition t0 
        whenTimeVar Timer -> flash          
}

Problem analysis

Per comportamento della lucciola si intende un'alternanza tra stato acceso e spento, in cui ogni stato dura circa 0.5 secondi con un periodo variabile di tipo randomico.

La lucciola, non interagendo con altri attori in questa fase, viene modellata come un QActor proattivo che, dopo uno stato iniziale, entra ciclicamente in uno stato flash, all'interno del quale modifica il proprio stato (acceso/spento).

  • la durata del lampeggio è gestita tramite un timer variabile;
  • la variabilità è introdotta tramite generazione randomica;
  • lo stato della lucciola viene visualizzato tramite un attore esterno ( griddisplay ).
